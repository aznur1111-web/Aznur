    About this directory

    How are repositories discovered?

    The index reads public repositories belonging to aznur1111-web, keeps repositories with GitHub Pages enabled, and excludes forks, archived repositories and the hub itself. New Pages-enabled projects appear on the next refresh; no manual list of URLs is needed.

    How does search work?

    Each app can describe itself with an aznur.json manifest at the repo root. The page fetches manifests, builds an inverted index in your browser, expands synonyms and ranks with field weights. Without a manifest, the page infers a name, description, type and subject from the repo name, description and GitHub topics.

    Is anything tracked?

    No analytics, cookies or search uploads. Search runs in your browser. The only network calls go to api.github.com and raw.githubusercontent.com to list your apps.
