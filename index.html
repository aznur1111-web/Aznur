    FAQ

    What is this?

    A static, searchable index of every web app, calculator and tool published by aznur1111-web on GitHub Pages. The list is fetched from the GitHub API when the page loads, so it is always fresh. Nothing is tracked.

    How does search work?

    Each app can describe itself with an aznur.json manifest. When the page loads, the manifests are fetched, an inverted index is built in your browser, synonyms are expanded, and ranking is applied. No servers, no third parties.

    How do I add an app?

    Enable GitHub Pages on the repo, then add an aznur.json to its root. Reload this page and the app appears. Repos without a manifest still appear, using the repo name and description.

    Is anything tracked?

    No cookies, no analytics, no fonts, no third-party requests. The only network calls are to api.github.com and raw.githubusercontent.com to list your apps.
